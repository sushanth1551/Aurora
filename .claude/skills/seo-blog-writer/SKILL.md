# seo-blog-writer

**Description:** Draft useful SEO content from a reviewed brief and evidence.

## Purpose
Produce an editorial draft with clear structure and claims traceable to
approved sources.

## When to use it
Use only when the user requests a draft and a suitable brief, audience, and
evidence set are available.

## Required inputs
- Approved content brief and target audience.
- Sources and claim-level evidence.
- Tone, length, locale, and prohibited claims.

## Execution workflow
1. Check that the brief and evidence meet the requested scope.
2. Outline an answer-first structure that serves reader intent.
3. Draft original prose and cite or annotate factual claims.
4. Identify unsupported claims, assumptions, and items needing review.
5. Return a draft for human review; do not publish.

## Expected outputs
Draft, outline or headings, source references, and a list of claims requiring
verification.

## Error handling
Pause if critical sources are missing or contradictory. Never invent quotations,
statistics, credentials, or citations.

## Quality requirements
Prioritize accuracy, readability, originality, accessibility, and user value.
Use keywords naturally and do not claim the draft is SEO-validated.
