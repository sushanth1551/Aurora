# Search results analysis criteria

Load this when interpreting an observed result page.

## The precondition

You may only describe results you actually observed. If no current search capability
or supplied result data exists, say so and stop — every claim about "what ranks" is
otherwise fabricated. This is not a degraded mode; it is a hard boundary.

State when the observation was made, from what location and language, and on what
device class. Results vary by all of these, and an undated observation is not
evidence.

## Read intent from what is there

The result set is the strongest available evidence of what the searcher is
understood to want. Read it in this order:

1. **Page types present** — product, category, guide, tool, forum, video, local.
   The dominant type is the format expected of a competitive entry.
2. **What the results have in common** — the shared job, not the shared keyword.
3. **Result features** — their presence indicates the kind of answer expected, and
   they change what a click is worth.
4. **Diversity** — a mixed result set means intent is genuinely mixed, and a single
   page format may not fit. Say that rather than forcing one interpretation.
5. **Freshness** — whether recent content dominates tells you if this is a topic
   where currency matters.

## SEO competitor is not commercial competitor

The pages competing for a query are frequently not the businesses competing for the
customer: marketplaces, publishers, aggregators, forums and reference sites. Keep the
two lists separate and say which one you are analysing. Advice built on the wrong
list is misdirected.

## The trap that ruins this analysis

**Presence in results is not proof of what caused it.** A page ranking with a
characteristic does not mean the characteristic caused the ranking, and copying
observed traits is a hypothesis, not a strategy. Common false conclusions: that a
word count is a target, that a structure is required, that a shared trait among top
results is the reason they rank.

State observations as observations, and any causal claim as `inferred` with the
reasoning shown.

## Content gaps

A real gap is a job none of the observed results does well, that the site can
credibly do. Not a topic nobody covers — that is usually a topic with no demand. Ask
why the gap exists before treating it as an opportunity.

## Generative and AI answer surfaces

When the observation includes them, note which sources are cited and what those
sources have in common structurally — clear direct answers, self-contained passages,
explicit entities, verifiable claims. Report only what was observed. Do not propose
techniques aimed at manipulating these systems.
