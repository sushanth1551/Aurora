# web-research

**Description:** Plan and synthesize a bounded, source-grounded web research task.

## Purpose
Create a transparent research summary in which factual statements can be traced
to sources. This skill describes intended work; provider integrations are not
implemented in the scaffold.

## When to use it
Use for a user-approved topic or company research request that needs external
sources and a concise evidence-based synthesis.

## Required inputs
- Research topic or company name.
- Scope, geography, date range, and output format when relevant.
- Approved sources or a configured research provider, if available.

## Execution workflow
1. Clarify the question, scope, and freshness needs.
2. Plan diverse, credible sources and respect access restrictions.
3. Collect source metadata and relevant passages; do not fabricate retrieval.
4. Separate sourced facts, interpretations, and unknowns.
5. Summarize findings with citations and note gaps or conflicts.

## Expected outputs
A scoped summary, source list, evidence-linked findings, uncertainties, and
recommended follow-up questions.

## Error handling
Report unavailable providers, blocked pages, stale sources, and conflicting
evidence. Never replace missing evidence with invented citations.

## Quality requirements
Use attributable, relevant evidence; preserve dates and URLs; minimize
unnecessary personal data; distinguish correlation from causation.
